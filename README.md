# Cheffify

This repository contains the product documentation for the Cheffify meal-planning and grocery-list application, inspired by Mealime, designed for iPhone-friendly usage, offline grocery editing, and a simple path to future household collaboration.

## Purpose

Cheff is a lightweight meal-planning tool focused on:

- recipe storage and scaling
- meal plan creation
- grocery list aggregation
- offline shopping support
- custom recipe upload with OCR-assisted import

The initial product target is a single-user PWA with a Python backend and an optional cloud deployment path.
